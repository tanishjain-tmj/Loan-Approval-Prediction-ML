# 🏦 Loan Approval Prediction

## 📌 About

A beginner-level Machine Learning project that predicts whether a loan application will be **approved or not approved** based on applicant information.

## 📊 Dataset

- Dataset: Loan Status Prediction
- Rows: 614
- Columns: 13
- Target: `Loan_Status`

## 🔄 Workflow

- Data Loading
- Data Exploration
- Missing Value Handling
- Categorical Data Encoding
- Feature Standardization
- Train-Test Split
- SVM Model Training
- Accuracy Evaluation
- Loan Prediction System

## 🤖 Algorithm

**Support Vector Machine (SVM)** with a linear kernel.

## 🛠️ Technologies

- Python
- NumPy
- Pandas
- Scikit-learn
- Google Colab / Jupyter Notebook

## 🎯 Prediction

The model predicts:

- `1` → Loan Approved
- `0` → Loan Not Approved
